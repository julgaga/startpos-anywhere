# v1.1.0

- Precise mode: in practice, the mod also records full checkpoints (triggers, moved blocks, colors, groups) every few blocks and respawns from them, so trigger-heavy levels spawn correctly.
- Only runs started from the real level start are recorded in precise mode.
- The % slider shows when a spawn will be precise.
- The four pause menu buttons are replaced by a small logo icon that opens a mod menu, so they no longer cover the pause menu. The menu also shows the recording status and links to the settings.
- Pick a manual start position from the mod menu (arrows + "Aller").

# v1.0.0

- First release.
- Automatic recording of your runs, one snapshot per block.
- Respawn, % slider and back-to-start buttons in the pause menu.
- Correct floor, ceiling and camera when spawning in ship, ball, UFO, wave, spider and swing.
- Manual start positions with configurable keys, a minimum gap and a "delete all" button.
- Per-level saving, discarded when the level is updated.
